# SPORE CYBERNETICS

**Innovation • Technology • Connectivity**

Responsive corporate website foundation for SPORE CYBERNETICS, an emerging ICT brand serving Uganda, Africa and international markets.

## Included
- Responsive landing page and mobile navigation
- About, solutions, delivery approach and contact sections
- Twelve ICT service divisions
- Plain HTML, CSS and JavaScript; no build step required

## Preview locally
Open `index.html` in a modern browser.

## Deploy to Cloudflare Pages
1. Connect this GitHub repository to Cloudflare Pages.
2. Select branch `main`.
3. Leave the build command empty.
4. Set the build output directory to `/` (repository root).
5. Deploy and test the generated `*.pages.dev` address before connecting the purchased domain.

## Before public launch
- Replace `hello@sporecybernetics.com` with an active company email.
- Add verified company registration details, phone, office address and social accounts.
- The contact link opens an email application; there is no enquiry database or admin portal yet.
- This is the public website foundation, not the full-stack business management platform.
- Never commit API keys, passwords, payment credentials or private customer data.
